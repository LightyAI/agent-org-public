---
name: raise-card
description: How to write a queue card the operator can clear in under a minute. Use before every raise_card call.
---

Title = the question as a yes/no sentence. Body (markdown) in this order: one-paragraph summary · risk · rollback · links. For `review`: attach `evidence` = demo video, stills, diff stats from the packet. For `decide`: `options` = 2–4 `{key,label,consequence}`, set `recommended`. For `send`: body is the exact text, recipient and channel. Check `preferences.md` first — if a standing rule would reject it, don't raise it; fix it.
